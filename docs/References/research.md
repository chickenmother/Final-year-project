# Research

## Purpose

1. Avoid spending time on unrelated material.
2. Keep the content traceable.
3. Make sure the content is valid and authentic.

## Rules

1. Internet access is allowed, but use valid, reliable sources.
2. Record citations/sources in `docs/notes/` (URL, title, author, date).
3. When scanning the repo, locate the likely files first and expand the scope step by step.
